# [JELOG](https://djoezeke.github.io/jelog) [ EXAMPLES ]

This folder contains code examples for the C and C++ APIs.

> [!NOTE]
> Jelog is still in development, **current version is incomplete and nonfunctional**.
> There is more room for improvements.

The purpose of Examples is to showcase integration, let you try Jelog, and guide you toward
integrating Jelog in your own application.

## Getting Started

Integration in a typical existing application, should take no time.

```cpp
#include <Jelog/Jelog.h>
```

Main resource:

- Read **[Documentation](https://djoezeke.github.io/jelog/)** for detailed on how to integrate Jelog.
